Este archivo contenia el token de la Cloud API y el Phone Number ID en texto plano.
Se quitaron por seguridad (estaban expuestos en el repositorio).

IMPORTANTE: ese token estuvo publicado, conviene ROTARLO en Meta (Business Manager
-> WhatsApp -> Configuracion de la API) y luego cargarlo por variable de entorno:
    WT_CLOUD_API_TOKEN = (token nuevo)
    WT_PHONE_NUMBER_ID = (id del numero)
mainCode.py ya lee esas variables de entorno si estan definidas.
